## Repositorio para Proyecto "Warning Labels Meet Recommender Systems: A Nutrition Aware Recipes Recommender"

## Entrega final

La entrega final del proyecto se encuentra completamente en la carpeta [`Entrega_final`](Entrega_final/).

Dentro de esta carpeta, cada modelo tiene su propia subcarpeta con su respectivo archivo `.py`:

- [`Content_based/content_based.py`](Entrega_final/Content_based/content_based.py)
- [`Ligth_fm/lightfm_local.py`](Entrega_final/Ligth_fm/lightfm_local.py)
- [`q_learning/q_learning.py`](Entrega_final/q_learning/q_learning.py)
- [`Deep_q_learning/dqn_recipe_recommender.py`](Entrega_final/Deep_q_learning/dqn_recipe_recommender.py)
- [`HTFRS/htfrs.py`](Entrega_final/HTFRS/htfrs.py)

### Cómo ejecutar

Para correr la entrega simplemente hay que ejecutar los archivos `.py` de cada carpeta, como se corre un `.py` normalmente desde la terminal. Por ejemplo:

```bash
python Entrega_final/Content_based/content_based.py
```

Cada script genera sus tablas y gráficos de resultados en la subcarpeta `Tablas_graficos` correspondiente.
